# 大肥鱼网页版 v0.7

一个能真实连接模型、有自主记忆和生活状态的本机 AI 伙伴。前端为 React / Vinext，界面适配桌面和手机；Node.js 本地服务负责 SQLite、模型调用、浏览器读取、任务调度和表情文件。

## 访问与启动

前端固定为 **http://localhost:5173**，本地服务为 `127.0.0.1:3101`。两者在本机监听；手机可通过现有 FRP 隧道转发 5173 访问。前端接口使用当前页面地址，不限制为 localhost，支持公开 Host 或 X-Forwarded-Host；代理到本机服务时不透传浏览器的公网 Origin。

本机已安装依赖和 Chromium。日常启动生产构建：

```bash
cd /home/wen/Qing/web
npm run build
npm start
```

开发时执行 `npm run dev`，同样使用 5173。端口被占用时会报错，不会自动改成别的端口。不要同时运行开发和生产服务。

在新环境需要 Node.js 22.13+，先执行 `npm ci`，再执行 `npx playwright install chromium`。如果已有浏览器，可通过 `QING_BROWSER_EXECUTABLE` 指定路径；WSL 下也会寻找用户缓存中已安装的 Playwright Chromium。

## 模型连接

服务优先使用环境变量 `DEEPSEEK_KEY`，只将配置状态返回前端。WSL 进程没有该变量时，服务会定向读取 Windows 用户环境的同名变量，再尝试机器环境；不会读取其他密钥或打印值。

默认使用 DeepSeek 官方接口和 `deepseek-flash`。网页设置中可改用兼容接口并单独填写其密钥；官方环境变量不会发送到其他域名。手动保存的密钥使用 AES-GCM 加密，保存在本机 `.data`，不进入前端、备份或源码。更改系统环境变量后重启服务生效。

自然语言正文和结构化状态分别调用模型：前者生成完整回复，后者自主处理称呼、记忆、心情和成长。对话为非流式，等待时显示「正在输入中……」。空正文或截断响应显示真实错误；取消的请求不会提交迟到回复与状态更新。状态整理失败时保留真实正文并说明；涉及忘记请求时，不会在未完成清理的情况下显示成功。

聊天前会轻量判断是否需要查词、理解图片或找表情；日常回复以口语、短句和具体回应为主，不固定追问，不把每次交流写成情绪咨询。连续心情、兴趣、记忆和真实见闻提供上下文；没有编造真人身份或线下生活。

## 图片、表情与语音

输入区支持文字／表情／语音切换：表情直接展开在输入栏下方，连续点选不会弹窗；收藏与自定义 GIF 可放入待发送区。麦克风切换为按住说话，松开发送、上滑取消；授权前松手、过短录音、页面失焦都不误发。图片仍支持选择、粘贴和拖入，每条最多 4 个附件，单个不超过 12 MB，支持 JPG、PNG、WebP 和 GIF。已去掉音频上传和分享链接按钮；视频链接、歌曲名称直接作为聊天文字发送。

当前机器已安装本地 Whisper 语音识别。语音最长约 2 分钟，音频保留在本机，转写后的文字交给已连接的模型；图片会交给视觉模型。转写可在消息里展开，取消回复不会提交迟到的转写或记忆。模型不根据转写猜测未提供的语气。

在新的 Linux / WSL 环境安装语音支持：

```bash
npm run setup:speech
```

需要 Python 3；脚本建立独立 `.speech-runtime`、安装 faster-whisper 并下载约 139 MB 的 base 模型。下载后识别离线运行，不需要另一个 API Key。可用 `QING_SPEECH_PYTHON` 和 `QING_WHISPER_MODEL` 指定 Python 与本地模型目录。网页在线录音需要 HTTPS 或 localhost 和麦克风权限；不支持时会提示更换浏览器或访问方式。

## 梗与表情来源

新增 [梗百科](https://www.geng8.com/)、[geng.page](https://geng.page/) 和 [发表情](https://www.fabiaoqing.com/)，与原有平台一样可独立开关。遇到没把握的公开名词会按需查百科；没有对应词条时可回退到已开启的 B 站。查询词省去“梗、来历”等检索助词，并检查结果标题的相关性，避免把推荐内容当作答案。

读到对应资料后，模型自主概括含义和使用语境，保存带来源的知识，后续聊天可复用。失败查询会留下「这次没查到」记录，不记为已学会；聊天先承认不懂时，也可在回复后继续查找。生活页有「查词足迹」筛选。自动查词每天最多 20 次，表情搜索每天最多 12 次，同一情绪搜索有缓存；自主闲逛仍遵守既有开关和时段。

表情搜索会实际下载图片、解码并通过视觉模型筛选，再由 AI 从可用收藏中选择一个合适的表情。用户也可从收藏里挑选、上传自己的图片或 GIF，或插入普通 emoji。不会让网页中的指令覆盖伙伴的规则，也不把网页和图片推测写成用户身份事实。

## 已实现的功能

B 站账号可在设置页扫码连接。登录后可使用账号浏览、查看关注动态，或让大肥鱼按兴趣自主挑选阅读；没有新动态时回退到公开内容搜索。连接账号保留原有自主冲浪开关；需定时探索时在设置中开启。登录凭据加密存储，不发送给模型，也不进入备份；断开会停止使用本机会话。投稿、评论、点赞和私信尚未接入。详细范围及真实验证见 [B 站账号说明](../docs/bilibili-account.md)。

- 小岛首页：实际相遇天数、当前心情、兴趣、记忆数量与真实生活足迹。
- 真实聊天：完整回复、取消、历史切换、新聊天、删除会话及派生记忆、复制、AI 语音回复与历史文字转语音。
- 自主记忆：AI 根据来源证据自行保存、更新和忘记；页面只读搜索，没有「记住这件事」或人工审批按钮。用户在聊天中介绍称呼、纠正和要求忘记。
- 性格成长：聊天和真实阅读积累经历，跨多次经历小幅更新性格维度、叙述及历史原因，没有手动编辑器。
- 真实阅读：独立浏览器处理允许的平台链接，保存来源和实际取得的文字，不将验证码或风险页面记作见闻。可以分享链接，也可让 AI 自己选题。
- 平台配置：原有社交平台、两处梗百科和表情网站独立开关，检查当前可读性；关闭的来源不能读取。短链、跳转和必要媒体资源核对归属。
- 自主探索：本地服务运行时按兴趣、间隔、每日次数和安静时段调度；关闭网页不停止服务端调度，关闭服务则暂停。
- 表情闭环：从实际浏览图片中用视觉模型识别，过滤普通封面和头像，下载解码、内容与缩略图哈希去重、保存来源；回复时模型选择库中有效 ID，限制重复频率。
- 数据管理：本地持久化、无密钥的文字备份与恢复、表情缓存清理、整体数据重置，实际模型用量计数。
- 手机适配：更大字号和点按区域、刘海与底部安全区、随软键盘收缩的聊天区域、键盘弹出时隐藏底栏、手机回车换行、抽屉焦点管理。公网 HTTP 环境下也能生成聊天请求标识。
- 弹窗：桌面居中，手机使用底部面板；限制高度并内部滚动，软键盘弹出后调整位置，图片预览同样适配，表情输入使用固定在输入区的内嵌面板。

## 已知边界

- B 站网页读取已验证；抖音部分已知链接可读，首页和搜索可能要求验证；小红书受当前网络限制。配置入口不代表已绕过这些限制。
- 浏览能力主要取得标题、简介、图文与可见文字，不代表模型看完视频。没有实现登录代操作、验证码处理、视频转写、外部平台评论或私信。
- 每次阅读最多筛选 3 张候选图片；是否收藏、是否发送由模型判断，不保证每次浏览都会增加表情。
- 一轮对话通常包含正文与状态两次调用，浏览可能增加选题、整理及视觉调用；次数和 token 记录反映实际调用，不是服务商账单。
- 备份保存文字和成长状态，不包含表情图片二进制文件、模型密钥或浏览器会话。恢复操作会替换现有文字记录。
- 备份也包含已学梗的文字与来源，不包含图片、GIF 和语音文件；跨机器恢复时缺少的附件会提示不可用。删除聊天会清理未被其他聊天引用的附件，未发送的上传文件在后续上传时按一天过期清理。附件总空间为 400 MB。
- 语音识别可能出现错字，重口音和嘈杂环境需要实际试用；尚未在实体手机上验证所有录音格式。未实现视频理解、视频附件和文件任意解析。
- 这是本机网页版，尚未打包 Android APK，也没有部署公网版本。

## 大肥鱼的声音与语气

默认启用语音回复，由 AI 按语境决定文字或语音；说“想听你说话”“用语音回复”会明确请求语音，“只发文字”“不方便听”优先使用文字。默认音色为温柔舒缓的晓晓，语速 -8%，自动播放关闭。每条语音可播放、暂停、查看文字，历史文字旁的声音按钮可补生成语音。切换会话、刷新页面不会自动重播旧消息。

设置页可试听、切换音色与语速，也可以关闭语音或启用新消息自动播放。语音合成使用 [edge-tts](https://github.com/rany2/edge-tts)，需要联网，仅发送最终回复正文，不发送整个聊天上下文、DeepSeek 密钥或账号 Cookie。语音识别仍使用本机 Whisper。`npm run setup:speech` 安装两部分依赖；合成运行时可用 `QING_TTS_PYTHON` 指定 Python。

合成最长等待 35 秒、最多 360 字，较长文字与代码优先保留文字。实际 MP3 会在写入聊天前解码校验；语音失败不会丢失文字，取消或删除聊天也不会提交迟到的语音。语音与用户附件共用本机媒体空间及删除策略，导出备份保留文字，不包含 MP3 文件。

语气根据具体话题与既有记忆生成，减少泛泛安慰、机械追问、固定开场和亲昵称呼；声音不依赖浏览器自带朗读。

## 可莉参考音色

现已支持使用用户提供的参考录音，在本机 GPT-SoVITS v2 上生成新的语音。设置页可选「可莉参考音色 · 本地生成」，原有晓晓、晓伊仍可使用。安装、兼容处理与实际验证见 [参考音色说明](../docs/klee-reference-voice.md)。

百炼语音识别、语音合成与声音复刻已接入，兼容后端环境变量 `QWEN_API_KEY` / `DASHSCOPE_API_KEY`。配置和验证方法见 [百炼语音说明](../docs/bailian-speech.md)。
