# 青屿 v0.5：自然聊天、真实查梗与多媒体

本轮调整弹窗定位和大小，重新组织聊天语感，并将梗百科、表情网站、用户图片/GIF/语音纳入真实聊天链路。前端继续固定运行在 5173，原有聊天、记忆、性格和连接配置保留。

## 行为

- 桌面弹窗显式居中，手机使用底部面板；限制宽高、内部滚动，软键盘缩小时避让。修复 CSS reset 移除浏览器默认 dialog 外边距后导致的位置问题。
- 普通聊天采用短句和具体回应，减少客服开场、复述、说教、固定追问和治愈文案；根据连续心情、记忆和真实经历接话。不用堆热梗模拟活泼，也不编造真人身份或线下活动。
- 梗百科 geng8.com、geng.page、发表情可独立配置。查词只发简短公开主题，检查词条相关性，实际取得正文后才保存带来源的概括。找不到也留下真实查询记录。
- 自动查询在回复前按需执行；若先回复“不懂”，还有回复后继续查找的分支。学习结果供后续对话使用，不需要用户审批记忆。
- 表情会从网站实际下载、解码、视觉筛选，再供模型选用；不使用假链接。原有收藏去重、发送间隔和容量设置保留。
- 用户可选 emoji、收藏表情、上传图片和 GIF、录音或上传音频；支持附件单发、配文字、图片粘贴与拖入、录音试听和取消。音频提供浏览器播放和文字转写。
- 本机 faster-whisper 进行语音转写，图片由已连接的视觉模型理解；照片推断不能直接变成用户身份或偏好。取消后的迟到结果不会写入。

## 实际验证

使用 `/tmp/qing-v05-live-final` 隔离数据库和 3102 服务进行真实模型测试，未将测试对话、称呼或录音写入用户数据库。

1. 从聊天中的“九阳哈基米南北绿豆浆”发起站内搜索，读取 geng.page 对应词条，保存含义、语境和来源；后续对话复用该知识。
2. 实际从发表情下载图片，视觉识别后收藏，真实回复中选择并发送收藏 ID。
3. 上传真实图片作为用户表情，模型根据画面接话。
4. 本机将中文音频转出“今天终于下班了，我想喝一杯乌龙茶”（转写为繁体字），再由真实模型回应。独立识别测试约 2.5 秒，完整聊天还包含模型和表情处理时间。
5. 闲聊和知识回用均得到完整非流式回复。语感属于实际模型输出，仍可能有多余的追问或修辞，不能把几条样本视为所有场景的保证；本轮进一步收紧了不必要叮嘱和虚构场景。

早期测试曾把“不相关的推荐词条”当作搜索结果。修正查询词规范化、标题相关性和模型 `supported` 标记后，最终测试查到对应词条。早期样本单独保留，不作为成功证据。

## 检查

- 31 项测试通过：包括原有记忆、成长、取消和代理，以及真实图片解码、语音证据、附件删除、二进制上传/Range 播放、查词开关、失败查询、错误词条过滤和回复后学习。
- TypeScript 检查及生产构建通过。
- 六页 × 320/390/768/1440 共 24 组导航和横向溢出检查通过。
- 手机交互检查覆盖软键盘模拟、回车换行、触控尺寸和焦点管理。
- 弹窗在四种宽度下均位于视口内；桌面居中、手机靠下，模拟键盘缩小到 480 像素时仍可操作。
- 浏览器验证图片配文字发送、语音附件单发、实际音频播放、emoji 选择，以及假麦克风录音取消/完成/试听。聊天 POST 被拦截，没有额外调用模型。
- 以上不是实体 iPhone/Android 的硬件测试。在线录音还受 HTTPS、权限和浏览器录音支持影响。
