# 网页版 v0.4 实现与验证

本轮从旧交互原型进入可运行的网页版。前端固定端口 5173，原型目录保留供历史参考，运行数据与旧演示浏览器存储独立。

## 实现

使用 Sites 提供的 Vinext 工程组织前端，重构为小岛首页、聊天、生活、记忆、表情收藏和设置。浅海蓝与暖白为主色，保留原创鲸鱼形象，桌面使用侧栏和聊天陪伴面板，手机采用底部导航及折叠菜单。

Node 本机服务在 3101 提供同源代理后的接口，使用 SQLite 存储真实数据。环境变量密钥在服务进程内读取，前端只拿到已配置状态；WSL 可读取用户指定的 Windows `DEEPSEEK_KEY`，不保存该环境变量的值到项目。

自然回复与结构化记忆状态分开处理，解决模型将自然回答混入 JSON 模式时产生空正文的问题。两项请求各有用途，不盲目重发同一个生成请求。记忆整理失败会记录状态，不编造保存成功；忘记操作未完成时不会返回已清理的成功消息。

阅读与表情收集使用真实 Playwright 浏览器和模型视觉接口，不使用预置演示回复或伪造图片。平台访问失败按实际原因显示。Android、账号登录和视频理解仍不在本轮完成范围。

## 真实验证

真实模型与网页测试使用独立临时数据库 `/tmp/qing-live-check`，没有将测试称呼、对话或收藏填入用户运行数据库。

- DeepSeek 官方接口连接测试成功。
- 从用户测试消息中提取称呼，并自主保存偏好；后续成功回复能召回乌龙茶信息。
- 用户要求忘记饮品偏好后，相关长期记忆清除。
- 实际读取 B 站猫猫表情图文，取得来源和正文，并形成模型感想。
- 视觉模型判断并收藏了 3 张实际图片，保存含义、标签及来源。
- 聊天中的震惊语境触发了真实表情选择，并随完整回复展示。
- 存在过模型空正文和格式异常的失败样本；修正处理流程后，最终 3 轮端到端真实模型测试均完成。失败记录没有伪装成成功回复。

## 移动端与 FRP 更新（2026-11-10）

沿用 Sites 前端技能，在保留小岛风格和桌面布局的基础上调整手机字号、次要文字对比度、首页卡片层次与底部导航。主要操作采用至少 44 像素点按区域，输入框使用 16 像素字体，避免 iOS 聚焦时自动放大；支持刘海和底部安全区。

聊天区域通过 Visual Viewport 感知键盘占用的高度，弹出键盘时收起底栏、保持输入区可见，收起后恢复导航。手机回车换行，通过发送按钮提交；桌面仍支持 Enter 发送。抽屉导航可通过遮罩、关闭按钮和 Escape 收起，管理焦点并避免访问被遮挡的内容。弹窗具有可访问标题。

FRP 修正位于前端服务代理：按应用当前 Host 或转发 Host 验证来源，再转发到 loopback 服务，不将公网 Origin 传给本机服务。无需固定白名单，可使用现有穿透地址。公网 HTTP 上缺少 `crypto.randomUUID` 时也能生成聊天请求标识。

验证记录：

- 19 项后端及来源代理测试通过，类型检查与生产构建通过。
- 六个页面 × 320、390、768、1440 像素宽度，共 24 组检查无横向溢出；320 像素设置页的网格最小宽度问题已修复。
- 手机浏览器检查覆盖导航焦点、抽屉关闭、输入字体、发送区域、回车换行、HTTP 请求标识、分享弹窗，以及 320/430 像素和横屏聊天布局。聊天 POST 被拦截，没有调用模型或修改用户聊天。
- 模拟软键盘导致 Visual Viewport 缩小到 480 像素，输入区保持在其内，底栏正确隐藏与恢复。这是浏览器模拟，不代表已在实体 iPhone 或 Android 上测试。
- 实际访问 HTTPS 穿透地址成功，健康接口正常；浏览器提交无效会话 ID 后返回预期 404，证明请求已通过来源检查且没有写入数据。
- 隧道 HTTP 入口由服务商返回 501 并跳转 HTTPS。HTTPS 证书当前为自签名；仅诊断时忽略证书错误，应用没有关闭证书验证。
