# B 站、抖音、小红书网页浏览实测

验证日期：2026-11-10，浏览器及补充测试为北京时间 12:00–12:08。此次只做只读验证，没有登录账号、处理验证码或修改 App 功能。

## 结论

| 平台 | 当前环境匿名浏览结果 | 对项目的实际意义 |
| --- | --- | --- |
| B 站 | 首页、搜索和 3 个详情样本均可读取 | 可作为浏览器读取路线的首个接入候选，尚不能宣称长期稳定 |
| 抖音 | 首页和站内搜索进入验证码页；2 个已知详情及沿合集发现的第 3 个详情可读取 | 已知链接阅读部分可行，完整自主找内容的入口尚未通过 |
| 小红书 | 探索、搜索和 2 个无签名参数的笔记链接均未取得正文 | 当前环境未验证通过，不能据此认定所有设备或登录状态都不可行 |

这是本次样本的结果。成功取得网页标题、简介或评论，不等于模型看懂了视频，不等于平台提供了不受限的内容 API。

## 验证方法

使用本地 Playwright 驱动 Chromium 158.0.8127.18，1366 × 900 桌面视口，中文语言，每个平台使用新的匿名浏览器上下文。没有读取用户日常浏览器资料、登录态或 Cookie。对照页面 `example.com` 正常加载，说明此次并非全部外网不可访问。

每个平台依次访问首页或探索页、关键词「猫」的搜索页及两个具体内容页，等待渲染后读取实际 DOM，保存页面标题、正文长度、少量摘要、内容链接数、图片加载数和截图。B 站另从本次首页实际发现的视频链接进入详情；抖音另验证展开后的评论与合集下一条。

没有修改浏览器指纹、求解验证码或使用签名逆向接口。初次脚本阻止被浏览器识别为 media 类型的请求，但页面仍可能通过 fetch/XHR 加载播放器内容，B 站截图出现了播放器画面；因此不声称本轮完全没有加载媒体。后续评论检查另阻止了常见媒体 URL。没有进行整段播放、视频下载、字幕取得或语音及画面理解验证。

另用当前会话的托管网页读取工具读取同类页面，作为与浏览器渲染路线的对照。该工具的失败不能推导出 DeepSeek Fetch 的实际结果；本轮没有使用或测试 DeepSeek API Key。

## B 站

### 实际通过的路径

1. [首页](https://www.bilibili.com/)返回 HTTP 200，页面取得 14 个按 URL 去重的视频详情链接及 26 张已加载图片。
2. [搜索「猫」](https://search.bilibili.com/all?keyword=%E7%8C%AB)返回 HTTP 200，主测试记录 37 个去重的视频链接。后续独立浏览器检查记录 73 个匹配的 DOM 链接节点；节点数包含重复链接，不能当作 73 条不同视频。
3. 两个已知样本 [手工猫咪](https://www.bilibili.com/video/BV1Axgg6aExW/)和[猫咪视频](https://www.bilibili.com/video/BV1i49cBwEyj/)均返回 HTTP 200，取得标题、作者、BVID、封面存在信息和相关推荐链接。
4. 从本次首页取得的新链接进入 [BV12vWx6mEyX](https://www.bilibili.com/video/BV12vWx6mEyX/)，同样取得标题、作者和实际简介。验证包含「发现新链接 → 读取详情」，并非仅访问预先知道的地址。

有的样本简介为空或只有占位符，不能因此生成不存在的正文。一个详情样本记录到 1 条页面脚本错误，但上述目标字段和截图仍成功取得；生产适配器仍需处理页面局部失败。

### 对照与建议

托管网页读取器对两个详情报告 HTTP 412，搜索页进入浏览器升级提示。故当前证据支持带渲染的浏览器路线，不支持「任意简单网页抓取工具都能读取 B 站」。

建议优先为 B 站制作浏览器读取适配器：先处理发现、标题、作者、简介与推荐，字幕、评论全量及视频理解另行验收。当前没有测试个人推荐、关注动态或登录后的能力。

截图：[搜索页](../artifacts/platform-browsing/bilibili-search.png)、[详情页](../artifacts/platform-browsing/bilibili-detail-1.png)。

## 抖音

### 实际结果

- [首页](https://www.douyin.com/)及[站内搜索](https://www.douyin.com/search/%E7%8C%AB?type=video)虽然 HTTP 为 200，但标题为验证码中间页，没有取得内容列表。这两项按失败处理。
- 两个已知样本 [7660872948165262579](https://www.douyin.com/video/7660872948165262579)及[7613600809083260879](https://www.douyin.com/video/7613600809083260879)返回 HTTP 200，可取得视频标题、作者相关信息、互动数量及合集链接。
- 使用另一个全新匿名上下文访问第一个样本，滚动到评论区域后，在页面中检测到 5 个评论项节点，说明至少部分公开评论实际可读取；不代表全部评论或全部回复都可读取。
- 页面会自动弹出登录提示。另一次全新匿名检查通过正常的弹窗关闭图标将其关闭，再滚动评论区域，仍检测到 5 个评论项，截图时有 1 项进入可视区域。此操作没有完成登录或验证码；可关闭的提示仍增加了无人值守浏览的复杂性，不能承诺每次都能这样读取。
- 从这个页面实际发现[合集下一条](https://www.douyin.com/video/7662231412393835226)，进入后取得正常标题与详情文字。这只证明沿当前合集继续浏览，不等于已经能访问任意推荐流。

托管网页读取器对两个详情均未取得可读行，站内搜索亦不可访问。截图中的播放器是否完成播放不是本次验收项；评论补充测试主动阻止媒体请求。

### 接入建议

先定位为「已知链接和部分合集的阅读适配器」。站内选题搜索、首页推荐及更多内容发现仍需另外解决，不能把已知链接成功说成完整的自主冲浪成功。可评估平台接口或用户自己的正常浏览环境，但尚未验证，不预设登录即可解决验证码问题。

## 小红书

### 实际结果

- [探索页](https://www.xiaohongshu.com/explore)和[搜索页](https://www.xiaohongshu.com/search_result?keyword=%E7%8C%AB)进入安全限制页面，显示当前网络风险，错误码 `300012`。
- 两个笔记样本 [669b9dfc0000000025007280](https://www.xiaohongshu.com/explore/669b9dfc0000000025007280)及[6762e05f000000000800f8b1](https://www.xiaohongshu.com/explore/6762e05f000000000800f8b1)没有取得正文，页面同时出现笔记暂不可浏览和网络风险相关信息，涉及 `300031` 与 `300012`。
- 这两个样本是从公开索引中发现的历史笔记地址，未附有效分享参数；不能排除内容下线、参数缺失等因素，不能仅凭笔记失败把原因全部归于网络。探索页独立出现网络风险，是当前环境受限的直接证据。
- 托管读取工具对探索页报告无法访问重定向后的登录页，两个笔记及搜索亦不可读。

### 接入建议

当前环境不适合直接承诺小红书无人值守浏览。下一项有意义的验证是用户正常网络、正式浏览器及有效分享链接；如需登录，由用户在正常入口完成后再验证实际可读内容。本轮未执行这些测试，也没有推断登录能解决当前错误。

## 对当前方案的调整

- 首期浏览平台验证和接入顺序改为：B 站优先，抖音保留已知链接读取候选，小红书待正常网络与有效链接复测。微博保留为配置候选，本轮没有验证。
- 各平台分别显示发现入口、详情读取、评论、图片和视频理解等能力状态，避免只有一个笼统的「已支持」。
- 遇到风控、验证码或无正文时暂停相应任务并报告实际状态，不将错误页面或搜索缓存当成真实阅读经历。
- 没有取得平台原图、动图或使用权判断的验证证据；本轮不能作为自动收集表情包已可行的结论。
- 未测试 Android WebView、后台运行、长期频率、真实账号和持续稳定性，不承诺本机浏览器样本能直接等价到手机上线效果。

主脚本需要可用的 Playwright 和 Chromium。可通过 `QING_PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块，通过 `QING_BROWSER_EXECUTABLE` 指定浏览器路径，再从项目根目录执行：

```bash
node scripts/verify-platform-browsing.mjs
```

默认输出到 `artifacts/platform-browsing`，会覆盖同名截图和主结果；如需保留不同批次，通过 `QING_BROWSING_OUTPUT` 指定新的输出目录。没有把第三方依赖、账号资料或 Cookie 写入项目。
