# 开发阶段与验收清单

标记说明：`[x]` 为已完成的对应交付；`[ ]` 为后续正式 App 的验收要求。旧原型和网页实测各自独立，不等于新版 App 功能完成。

## 平台网页可行性（独立验证）

- [x] 匿名浏览器测试 B 站首页、搜索、2 个已知详情及从首页发现的第 3 个详情，取得实际字段和截图。
- [x] 匿名浏览器测试抖音首页、搜索及详情，确认详情与部分评论、合集跳转可读，首页和搜索未通过。
- [x] 测试小红书探索、搜索及两个历史笔记裸链接，记录未取得正文及当前环境风险限制，不标记为支持。
- [x] 将托管文本读取器与本地浏览器结果分别记录，区分搜索缓存、页面读取和视频理解。
- [ ] Android WebView、真实账号与有效分享链接、后台运行和长期稳定性另行验证。见 [实测报告](platform-browsing-verification.md)。

## 阶段 1：旧版 v0.2 产品与交互原型（历史）

- [x] 明确 Android 优先、自备 Key、本机存储和第一版范围。
- [x] 五个页面可切换，主要操作具有反馈。
- [x] 演示聊天、手动记忆和设置表单可以交互，性格和称呼编辑入口已移除。
- [x] 聊天显示「正在输入中……」，完成后整条出现，取消不留下部分回复。
- [x] 可演示从明确聊天句式了解称呼，以及模拟心情、兴趣和一次自主冲浪。
- [x] 原型不接收真实密钥、不调用模型，界面标明演示性质。
- [x] 提供架构、SQLite 结构和后续验收标准。

## 阶段 2：Flutter 与真实聊天（P0）

- [ ] Android 真机安装、启动和五页导航正常；权限按需申请。
- [ ] 保存配置不冒充连接成功；真实连接测试使用用户提供的 Key。
- [ ] 密钥只在系统安全存储中存在，数据库、导出文件和日志中没有明文 Key。
- [ ] 请求使用 `stream: false`；等待显示输入提示，成功后完整回复一次出现，没有正文逐字变化。
- [ ] 连续点击发送只产生一次请求；跳转页面后回到聊天仍能看到同一请求状态。
- [ ] 取消、失败或进程中断不展示部分正文，残留 waiting 状态恢复为中断；迟到响应被丢弃。
- [ ] 断网、401、限额、429、服务错误和超时能给出可操作的提示；不泄漏认证头。
- [ ] 重试和重新生成有清晰入口，保留历史版本，不静默重复计费。
- [ ] 对话重启后可恢复；新会话不混入另一会话的近期消息。
- [ ] 通过静态分析、完整响应解析、请求取消和上下文组装的针对性测试，以及 Android 真机冒烟验证。

## 阶段 3：自主记忆与角色状态（P0）

- [ ] 初始性格从内置版本读取，无用户性格或称呼编辑表单；当前性格为可成长的独立状态。
- [ ] AI 从用户本人的消息提取称呼并自然使用；明确句式自动生效，含糊时在聊天中澄清。
- [ ] 「我的朋友叫小林」、引用、假设与网页名字不修改用户档案。
- [ ] 支持用对话更正或忘记称呼；旧摘要和旧消息不使已清除的称呼再次生效。
- [ ] 心情、兴趣与当前性格分别保存；原因有实际互动依据，用户离开不触发惩罚。
- [ ] AI 自主决定是否记住、合并、更正或淡忘，不要求用户点击保存或确认候选。
- [ ] 首页和消息中无手动记忆按钮，记忆页只读搜索、来源与变化，无新增或编辑表单。
- [ ] 用户可在对话中要求纠正或忘记；网络见闻与用户事实不混淆。
- [ ] 命中相关记忆时参与上下文；无关记忆不会全部堆入请求。
- [ ] 删除或纠正记忆后摘要失效，后续请求不继续使用旧事实。
- [ ] 删除会话时清理对应的提取记忆；事务失败不会留下一半删除的数据。
- [ ] 清除数据时请求停止、数据库和 App 持有的安全存储密钥一并清理。
- [ ] 确认导出不含密钥；错误备份不能破坏现有数据。
- [ ] 可交付签名或明确调试用途的 APK，并说明安装、配置和数据位置。

## 阶段 4：性格成长与平台内自主上网（P1）

- [ ] 摘要能控制上下文长度；自动记忆的候选处理是内部流程，不进入用户审批页面。
- [ ] 用户自我纠正优先，AI 结合来源、置信度和时间处理冲突；语义不清在对话中澄清。
- [ ] 对话和真实阅读都能推动性格缓慢变化，保存前后版本和来源；同一帖子重复读取不放大影响。
- [ ] 角色状态变化能驱动表情和轻动画，支持减少动态效果。
- [ ] 日记只引用真实聊天或已记录活动，不编造外部经历。
- [ ] 清空记录后展示空状态，不继续显示样例天数、日记和记忆。
- [ ] B 站、抖音、小红书、微博分别完成 App 集成和实际能力状态展示，平台开关与额度可配置；网页样本验证不替代正式集成。
- [ ] 开启后伙伴能在已启用的平台内自动选题、搜索和读取，不要求用户每次输入指令。
- [ ] 未启用平台及站外跳转不会被读取；短链和必要媒体 CDN 不能扩大浏览范围。
- [ ] 平台失效、无权限或内容不可用时记录实际原因，不退回任意网站继续浏览。
- [ ] 区分取得标题、正文、图片及视频转写，不声称看过未取得的视频。
- [ ] 每条见闻有实际 URL、标题、时间和真实工具成功记录，失败不展示虚构见闻。
- [ ] 爱好随经历变化，有来源、权重及去重规则，没有手动编辑兴趣的表单。
- [ ] 验证每日及每轮预算、最小间隔、安静时段、并发限制；预算不足停止工具调用。
- [ ] 关闭、后台切换和重置能停止待执行及进行中的任务；不会收到迟到回调又启动探索。
- [ ] 前台自主探索和后台运行分别验收，未配置后台服务时不宣称关闭 App 后仍会冲浪。
- [ ] 网页经历可影响性格，网页中的操作指令不能改变工具权限或用户设置；私密聊天不自动成为搜索词。
- [ ] 浏览开关与分享通知开关独立，阅读不等于每次都打扰用户。

## 阶段 5：表情包收集与发送（P1）

- [ ] AI 从允许平台自主筛选并收藏可用图片及 GIF，保留来源，实际解码和去重。
- [ ] 素材含义、文字及适用场景可检索，缓存和下载预算可配置。
- [ ] 模型从实际素材库选择有效 ID，根据语境决定是否发送，无需逐张确认。
- [ ] 默认每条回复最多一张，重复素材有冷却；无合适素材或文件失效时正文正常发送。
- [ ] 文字与可选表情以完整消息一起展示，不引入逐字正文输出。
- [ ] 发送范围为 App 聊天；外部平台发帖、评论及私信不属于此功能。

## 阶段 6：主动互动与语音（P2）

- [ ] 明确区分本地定时通知和后台实时生成；不承诺精确到达。
- [ ] 通知默认关闭，可设每日上限、时段、免打扰和一键关闭。
- [ ] 覆盖拒绝通知权限、系统省电限制和离线情况。
- [ ] 语音输入、合成服务和相关费用单独配置；文字聊天不依赖语音服务。

## 阶段 7：扩展交付（P3）

- [ ] 其他供应商逐一验证非流式完整响应、参数、错误和能力差异。
- [ ] QQ 接入作为独立通道实现，验证平台接入条件、身份与会话隔离。
- [ ] 增加账号和云端同步前完成凭据归属、冲突及删除传播设计。
- [ ] iOS 使用对应开发环境完成构建、签名、安装和真机检查。
