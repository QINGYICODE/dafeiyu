# 原型验证记录

日期：2026-11-10，v0.2。对象为 HTML 交互原型及设计阶段 SQLite 结构，不是 Android App 测试。

## 已通过

- Chromium 无头浏览器在 320、390、768、1440 像素宽度下切换全部五页，无页面水平溢出。
- 等待时显示输入提示，没有部分正文；完成后整条回复出现；取消后没有迟到回复。
- 等待中切换页面再返回保持同一个任务；刷新后显示中断。
- 从消息记入记忆，搜索、编辑及确认删除；包含 HTML 标签的输入仅作为文本展示。
- 人格和称呼编辑表单已移除；从明确聊天句式了解称呼、更正、忘记和刷新保留。
- 从 v0.1 演示数据升级后保留聊天与记忆，忽略原先手填的称呼和人格。
- 心情随演示聊天和见闻变化；自主冲浪开启后自动展示一次预置见闻，兴趣随之更新。
- 冲浪关闭、页面隐藏及重置能停止演示任务，没有重复见闻。
- 设置要求 HTTPS 地址；真实密钥输入禁用；演示连接提示不会报告真实成功。
- 重置恢复初始记忆、消息及生活状态，清除已了解的称呼。
- 浏览器无未捕获脚本错误；操作期间没有对外部域名发起请求。
- SQLite 结构在内存数据库中执行成功，版本为 2，完整性检查结果为 `ok`；拒绝未完成助手消息带正文，删除称呼来源消息时清除称呼档案。
- HTML 无重复 ID，SVG 引用均有效。
